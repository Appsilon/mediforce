# Mediforce

Mediforce runs the work that gets clinical and regulatory documents produced,
reviewed and signed off. A **workflow** is a graph of **steps**; each step is done
by a person, a script, a built-in action or an agent; each execution is a **run**
you can inspect afterwards.
