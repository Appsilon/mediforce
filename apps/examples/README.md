# examples

Grouping directory for small, self-contained example workflows. Each
subdirectory is its own workflow package.

- [`personal-automations/`](personal-automations/README.md) — action-only
  reference templates: webhooks, HTTP chaining, reshape, scheduled push
  notifications.

These are meant to be read and copied. For the production-grade reference —
control modes, Docker build mode, skills, MCP governance — see
[`golden-standard-workflow`](../golden-standard-workflow/README.md) instead.
