# PLAN-0017: Colocated package and app READMEs

Implementation plan for the gap [ADR-0017](./0017-retire-llm-maintained-wiki.md)
names in its Consequences section. Not yet executed. Move this file to
`docs/archive/` once it is.

## What

Give every package and app a `README.md` in its own directory, seeded from the
entity pages now sitting in `docs/archive/knowledge-base/wiki/entities/`, and
record the convention so new packages get one.

**Missing today — 11 packages:** `agent-runtime`, `cli`, `container-worker`,
`core-actions`, `example-agent`, `mcp-client`, `mediforce-mcp`, `platform-api`,
`platform-core`, `platform-infra`, `workflow-engine`. Only `platform-ui` has
one.

**Missing today — 10 apps:** `backlog-triage`, `community-digest`, `examples`,
`media-monitoring`, `mediforce-reviewer`, `sdtm-rule-migration`, `tealflow`,
`tealflow-cowork`, `team-pulse`, `workflow-designer`. `golden-standard-workflow`,
`landing-zone`, `mediforce-fullstack` and `protocol-to-tfl` have one.

## Why

Three facts from the ADR-0017 audit:

**The gap is real and currently unfilled.** `docs/concepts/architecture.md` is
77 lines of Steps / Processes / Autonomy / Compliance with no package graph.
After the wiki retirement, "what is `packages/agent-runtime` for?" has exactly
one answer: the one-line `<stack>` block in `AGENTS.md`. That is a regression
against the pre-retirement state, accepted deliberately and tracked here.

**Colocation is what makes it stick.** Every page that died in the wiki
documented *deleted* code, because nothing in a `git rm -r packages/foo` diff
points at a wiki page three directories away. `packages/foo/README.md` is
carried off by the same `git rm`, and anyone editing `src/` has it in
peripheral vision. This is geometry, not discipline — the reason no re-ingest
cadence would have saved the wiki.

**The content is cheap because it was already written.** These are not 21
READMEs from scratch. Twelve have a draft in `archive/` that needs a freshness
pass; the rest are short.

## How

1. **Write the convention first**, in `docs/README.md` under "Where new docs
   go": a package or app documents itself in its own `README.md`; `docs/`
   covers cross-cutting concerns only. Without this the next package ships
   without one and the gap reopens.

2. **Port the 12 archived pages.** For each, verify against the code before
   copying — `workflow-engine.md` was ~90% accurate at retirement but listed
   `TriggerHandler` and `src/graph/`, both gone. Drop the wiki frontmatter
   (`type:`/`created:`/`sources:`) for the repo convention
   (`status`/`audience`/`last_reviewed`). Cut the `## Sources` section — a
   colocated README does not cite the directory it lives in.

3. **Write the remaining 9.** Keep them short. A README that restates
   `src/index.ts` earns nothing and rots; ADR-0017 retired a whole system built
   on that mistake. Aim at what the code does not say: what the package is
   *for*, what depends on it, what you must not do to it.

4. **Follow `docs/contributing/doc-style.md`** — these are agent-facing.

5. **Verify:** `pnpm check:docs`, and confirm every `packages/*/` and `apps/*/`
   has a `README.md`.

6. **Then delete the ported pages** from `docs/archive/knowledge-base/wiki/entities/`
   and note it in the retirement README's "where the surviving content went"
   table, so the archive does not keep a second copy that can disagree.
